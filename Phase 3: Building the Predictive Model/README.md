# Folder Description
This is the folder for Part 3 of the project, containing materials related to the development of the HFMD prediction model. 
This phase consists primarily of three parts:
* Preprocessing of meteorological and HFMD data, data normalization, and splitting into training and test sets.
* Train and evaluate various models, including ARIMA, SARIMA, and ARIMAX series models, and explore ways to combine these models with machine learning methods.
* Select the best model for interpretability analysis to investigate the impact of meteorological factors on model predictions.
# Folder Contents
* Code used for model training and evaluation, built using Notebooks.
* The output results generated during model training and evaluation are saved in .csv format.
* Model files are stored in .joblib format and can be read using the joblib library in Python.
